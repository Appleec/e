# @elinzy/logger

## Install

```shell
npm install @elinzy/logger
```

## Usage

```js
import * as L from '@elinzy/logger';

// compact
L.info('Item-1');
L.success('Item-1');
L.error('Item-1');
L.warn('Item-1');
```
